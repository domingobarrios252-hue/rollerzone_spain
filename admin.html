¿Cómo obtener el token de GitHub?
1. Ve a github.com/settings/tokens
2. "Generate new token (classic)"
3. Marca el permiso repo (acceso completo)
4. Copia el token y pégalo aquí
El token se guarda solo en tu navegador, no se envía a ningún servidor.
